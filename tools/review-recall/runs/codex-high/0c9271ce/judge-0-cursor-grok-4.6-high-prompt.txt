title: Driver teardown holds feed mutex while closing sockets, enabling a runtime hang.
The deferred teardown acquires `feed_mu`, sets `feed_fd = -1`, and then calls `close` on both FDs before unlocking. `close` can block in-kernel on kqueue/socket teardown, so this can park the driver while still holding `feed_mu`; the flooder then blocks on the same mutex and the worker can stop making progress, turning the repro into a long hang instead of terminating.
