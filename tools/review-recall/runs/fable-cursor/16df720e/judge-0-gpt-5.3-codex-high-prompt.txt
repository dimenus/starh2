title: The cancelAll(.keep) conservation test runs on the default single executor, so the callback-vs-drain race it claims to exercise cannot occur.
The test comment says some operations are 'completing on the loops right now (their callbacks racing the drain)', and the commit message names 'claim vs cancelAll's drain' as the edge under test.
